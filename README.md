# Studi Kasus: Bridging Global Infrastructure to Address Local Challenge with HPC

Repositori ini berisi implementasi studi kasus sederhana berdasarkan materi *Informatics Practitioner Lecture Series* mengenai pemanfaatan High Performance Computing (HPC) untuk menyelesaikan tantangan lokal.

## Deskripsi Studi Kasus
Studi kasus ini mengambil contoh **Prediksi dan Analisis Kualitas Udara (PM2.5)** di tingkat lokal. Meskipun infrastruktur skala besar (seperti supercomputer) beroperasi di tingkat global, mahasiswa informatika berperan sebagai **"Integrator"** yang menjembatani teknologi tersebut untuk menyelesaikan masalah nyata di lingkungan sekitar.

## Struktur File
- `main.py`: Program Python untuk memproses dan menganalisis data sensor udara lokal.
- `data_pm25.csv`: Dataset sampel pembacaan PM2.5 dari beberapa wilayah.

1. Pastikan Python sudah terinstal di komputer Anda.
